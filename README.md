## Project Overview

This repository contains five Python notebooks exploring stock market prediction through machine learning, deep learning, and news sentiment analysis. It covers data preprocessing, model development, and performance evaluation.

## Projects

### 1. Fundamental Analysis — `Fundamental.ipynb`
Explores stock price movement prediction using Logistic Regression and historical stock data.

### 2. Machine Learning — `Machine.ipynb`
Contains an intended Support Vector Machine (SVM) classification approach. The implementation requires validation and correction before its results can be relied upon.

### 3. Random Forest Prediction — `RF.ipynb`
Uses a Random Forest classifier to predict stock price direction and examine feature importance.

### 4. Stock Market Sentiment Analysis — `Senti.ipynb`
Uses news headline processing and an LSTM neural network to classify sentiment-related market movement.

### 5. Technical Analysis — `Technical.ipynb`
Uses normalized stock data and LSTM layers to classify the direction of future stock prices.

## How to Run

1. Open the required notebook in Google Colab.
2. Obtain the dataset referenced in the notebook.
3. Install any missing Python dependencies.
4. Update file paths to match your environment.
5. Run the notebook cells in order.

## Notes

- Model performance should be verified by rerunning each notebook.
- Time-series data should be split chronologically to avoid data leakage.
- Dataset availability and licensing should be checked before redistribution.
